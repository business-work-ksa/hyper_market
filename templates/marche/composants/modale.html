{% load i18n marche %}{% comment %} Composant — Modale de confirmation (docs/26, §4.5) Paramètres : id, titre, texte, action (URL du formulaire POST), libelle_confirmer, variante_confirmer (défaut primary), libelle_annuler (défaut « Annuler »). Ouverture : un bouton `data-modale-ouvrir=""` (static/js/marche.js). Sans JavaScript, le bouton d'ouverture est un vrai lien ou un vrai formulaire : la modale n'est qu'un confort. Élément natif ouvert par `showModal()` : le reste de la page devient inerte, le focus est piégé dans la modale, Échap la ferme, et le focus revient au bouton d'ouverture. Quand l'utiliser : confirmer une action qui engage (vider le panier, annuler, confirmer une réception) — ce qu'on ne peut pas défaire. Quand ne pas l'utiliser : pour une information (un bandeau suffit) ; pour un formulaire long (une page dédiée se partage et survit à un retour arrière) ; jamais à l'ouverture d'une page. Accessibilité : `aria-labelledby` vers le titre, `aria-describedby` vers le texte ; bouton de fermeture nommé ; l'action destructrice n'a pas le focus initial (c'est « Annuler »). {% endcomment %}
